## Project Description
DivineGear is an e-commerce website for gaming accessories. The website allows users to browse gaming products, search and filter products by category, view product details, create an account, log in, and add products to a shopping cart.

## Features
- Responsive e-commerce website
- Home page with featured products
- Dynamic product listing
- Product category filtering
- Product search
- Individual product details
- Product quantity selection
- Shopping cart
- Cart total calculation
- User registration
- User login and logout
- Form validation
- LocalStorage for users and cart data
- Async/Promise product loading
- GSAP product card animations

## Technologies Used

## How to Run the Project
1. Open the DivineGearEcommerce folder in Visual Studio Code.
2. Make sure all project files and folders are in their correct locations.
3. Open index.html.
4. Run the project using Live Server.
5. The DivineGear home page will open in the browser.
6. Use the navigation bar to browse the Products page and other website features.
